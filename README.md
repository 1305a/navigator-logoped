# Навигатор логопеда — кликабельный прототип

Демонстрационный макет цифровой среды логопеда: React + TypeScript + Tailwind CSS + shadcn/ui, без бэкенда и базы данных. Все данные захардкожены и хранятся только в памяти приложения — обновление страницы сбрасывает состояние.

## Запуск

```bash
bun install
bun dev
```

Откройте адрес из вывода (по умолчанию http://localhost:5173).
